# Card# 火柴杀（Matchstick Kill）

一款用 Python 编写的开源卡牌对战游戏。12 位角色、65 张卡牌、完整装备系统。

## 项目简介

火柴杀是一款回合制卡牌对战游戏，玩家选择不同角色，通过手牌、技能、装备进行对战。

### 特色
- 🎭 12 位角色，各有独特技能与被动
- 🃏 65 张完整卡组（普攻/物理/法术/锦囊/防御/战术）
- ⚔️ 全套装备系统（通用 + 12 件角色专属）
- 🎯 控制、爆发、辅助、坦克四大职业定位
- 🎮 支持技能冷却、buff/debuff、复活、决斗等复杂机制

## 运行环境

- Python 3.8 或更高版本
- 无需安装任何第三方库

## 局域网联机版
（1. 角色技能：大部分只有“简易壳子”
联机版为了实现同步，所有技能判定都是在主机端（Host）直接执行的。我砍掉了大量需要“快照”和“回溯”的复杂技能：

完全没实现：秦默的【复生献祭】、多斯的【复生仪式】（复活机制需要处理阵亡玩家重新入场，网络同步非常复杂）、枪手的【时空回溯】（无快照）、玖恒的【时间回溯】（无快照）、拾荒者的【废土壁垒】（免疫判定逻辑太复杂）。

极度简化：毒猎的【腐毒侵蚀】（没处理手牌上限永久-1）、帝郡的【罪罚锁狱】（只做了伤害转移目标，没做持续回合拦截）。

防御技能：在联机版中，受伤防御被简化成了 apply_damage 里的硬性判定（比如防弹背心直接减伤），而不是像单机版那样弹出“选择防御选项”的窗口。

2. 卡牌与装备：细节丢失
普攻变体缺失：联机版只保留了基础的【直击】和【重击】，单机版中你喜欢的【连击】、【快刺】、【横扫】等进阶普攻在联机版牌堆里没有放进去。

装备自动触发机制被砍：飞行滑板、机械猎犬、能量护盾等装备的自动判定，在联机版里是硬编码在主机的 apply_damage 里的，没有详细的UI提示，也没有把光能脉冲炮等装备的减CD效果实装。

拆除和抢夺：虽然代码里有拆和抢的逻辑，但因为缺乏装备栏上限判断的绝对严谨性（比如玖恒的拓械扩槽），可能偶尔会出BUG。

3. 响应式交互（大问题：阻塞与卡死）
防御响应死锁：这是目前联机版最大的隐患。单机版可以随时弹窗选防御，但在联机版里，我问你“是否使用躲闪”是阻塞主线程等待60秒的。如果这时候一个人掉线、发呆，或者网络波动，整个游戏直接卡死。

目标选择机制不完善：出牌打谁、给谁用【麻醉剂】，现在都是极其简陋的“弹出列表让你选数字”。一旦4个人同时行动，或者遇到“决斗”（双方互动的卡牌），目前的网络框架根本处理不了同时选目标。

4. 联机体验与容错（完全没做）
没有掉线重连：如果有人网络闪断，直接崩。

没有回合倒计时：一个人拖着不出牌，另外三个人只能干等。

没有观战模式：4个人满了之后，第5个人无法加入房间。

没有聊天系统：4个人的局域网，居然不能打字交流，这其实非常影响体验。

决斗未实装：联机版里保留了决斗的牌，但具体“3轮同归于尽”的判定在联机同步中极其容易出现逻辑不同步（主机算了一次，客户端又算了一次），所以实际上是废的。）
